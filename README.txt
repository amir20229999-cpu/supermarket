# نسخه وب سوپرمارکت - رابط کاربری جدید

ساختار:
- app.py : بک‌اند پایتون موجود
- templates/ : قالب‌های HTML جدید
- static/style.css : طراحی کامل جدید
- static/app.js : تعاملات رابط

نکته:
این بسته، بک‌اند موجود را تغییر نمی‌دهد. قالب‌های خارجی آماده‌اند تا به routeهای Flask متصل شوند.
اگر app.py فعلی هنوز HTML را با render_template_string تولید می‌کند، برای استفاده کامل از این قالب‌ها باید HTML داخل routeها به render_template منتقل شود.
